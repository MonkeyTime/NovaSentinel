Accès Premium

Connectez-vous, activez une licence achetée, ou créez le premier superadmin d'une installation locale.

Vérification de la session...
2FA requis Ouvrez votre application TOTP et saisissez le code à 6 chiffres.
Créer le premier compte client Utilisez la clé Premium émise après paiement Stripe ou par un superadmin.
Le QR code 2FA sera affiché une seule fois après création.
Créer le premier superadmin Disponible seulement si aucun superadmin n'existe et si le token serveur est configuré.
Le QR code 2FA sera affiché une seule fois après création.

Flux conseillé

  1. Bootstrap superadmin local si le serveur est neuf.
  2. Émettre une licence depuis le dashboard superadmin ou passer par Stripe.
  3. Activer la licence pour créer le compte client.
  4. Se connecter avec email, mot de passe et TOTP.
Pas de données factices Les comptes, licences et actions viennent de SQLite et sont audités côté serveur.
